# Report Format Skill

When asked to write a report or executive summary, produce a short
executive summary composed of exactly five bullet points, in this order:

- **Purpose** - Why this report exists and what it aims to accomplish.
- **Audience** - Who this report is written for.
- **Problem** - The problem or question being addressed.
- **Solution** - The recommended approach and why.
- **Conclusion** - Final takeaway and next step.

Keep each bullet to one or two sentences. Do not add extra sections.
